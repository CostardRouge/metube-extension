MeTube Sender

Send YouTube links to your self-hosted MeTube.

Server

Include the path prefix if MeTube is served under one, e.g. https://example.com/metube.

Sent as HTTP Basic auth (e.g. Traefik basicAuth) with every request. Leave both empty if MeTube isn't behind auth.

Download defaults

Download type

Sub-folder of MeTube's download directory. Needs CUSTOM_DIRS on the server (and CREATE_CUSTOM_DIRS for folders that don't exist yet).

"Audio only (m4a)" in the context menu and the popup always uses M4A at best quality, into the same folder.

Player on YouTube

Language codes, comma-separated. The player loads <video>.<lang>.vtt for each one it finds next to the file. MeTube only writes them with writesubtitles in YTDL_OPTIONS (see the README).

Keyboard shortcut …

On a YouTube video page, the shortcut (or the popup's Play button) opens the video from MeTube in an overlay.

Saving asks for permission to access your MeTube host. Settings, password included, are stored only in this browser's extension storage.
